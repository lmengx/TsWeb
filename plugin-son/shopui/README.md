# ShopUI — 虚拟旅商商店

**手持锡斧挥动** → 在脚底召唤一个**仅自己可见**的虚拟旅商；再次挥动拉回身边；关闭对话或下线自动消失。
旅商商店为 **40 槽（10×4）**：上方商品区 + 底部 3 个**雕像控件**，点击雕像切换商店。

## 交互

| 操作 | 效果 |
|------|------|
| 手持**锡斧**按下使用键（挥动） | 召唤虚拟旅商（仅自己可见，站定在脚底） |
| 旅商存在时**再次挥动锡斧** | 把旅商拉回身边 |
| 点击旅商对话 → 点"商店" | 打开旅商商店（40 槽：37 商品槽 + 3 雕像槽） |
| 点击商店里的**雕像** | 雕像被"消费"（不进背包）→ 立即切换对应商店 |
| 点击旅商对话 → 关闭对话 | 旅商自动消失 |
| 直接下线 | 自动清理 |

## 构建

```bash
cd plugin-son/shopui
dotnet build -c Release
```

产物：`bin/Release/net9.0/shopui.dll`，放入 TShock 的 `ServerPlugins/` 目录。

## 实现原理（1.4.5 / TShock 6.1.0 源码实证）

### 仅自己可见（核心）
- 服务器创建**真实**旅商 NPC（368），出站包经 **`OTAPI.Hooks.NetMessage.SendBytes` 钩子**（Omni Ghost 同款）定向过滤：
  - `23 号包 SyncNPC`：body 前 2 字节 = NPC 索引，匹配虚拟旅商且接收者≠所属玩家 → `args.Result = Cancel`
  - `40 号包 SyncTalkNPC`：body 中 talkNPC 匹配虚拟旅商且接收者≠所属玩家 → Cancel
- 其他玩家客户端收不到该 NPC 的任何包 → 实体不存在 → 完全不可见、无法交互

### 挥动检测
- `GetDataHandlers.PlayerUpdate` + `Control.IsUsingItem` false→true 上升沿 + 手持槽位物品 `== 3500`

### 商店刷新
- **104 号包 ShopOverride**（TrProtocol 实证）：`[2长度][104][byte 槽位][short 物品][short 数量][byte 前缀][int 价格][byte buyOnce]`，socket 直发
- `GameUpdate` 计数每 300 tick（5 秒）应用一次；客户端 `Main.npcShop>0` 时才应用，未开商店自动忽略

### 雕像切换商店（购买触发）
- 雕像在商店中价格 0 → 点击购买 → 客户端把雕像放入背包槽 → 发背包槽更新包（`PlayerSlot`）
- `GetDataHandlers.PlayerSlot` 钩子检测到雕像类型 → `args.Handled=true` 拦截 → `SendData(PacketTypes.PlayerSlot, ...)` 回滚客户端槽（雕像消失，原物品保留）→ 切换 `_currentShop` → 立即 104 应用新商店

## 已知限制

- 对话面板需玩家点击旅商后打开（服务端无法强制弹出）
- 服务器端存在真实 NPC 实体（对其他系统如 NPC 计数有轻微影响）
- 旅商站定不动（`aiStyle=-1`）

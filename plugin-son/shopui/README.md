# ShopUI — 虚拟旅商商店

> ⚠️ **已并入 TSWeb 主插件（2026-08-14）**：本目录的独立插件版本保留作备份/参考。
> 实际运行版本在 `plugin/ShopUI.cs`（核心逻辑）+ `plugin/ShopUIConfig.cs`（配置化：内容由 `{TShock.SavePath}/TSWeb/ShopUI/shopui_config.json` 驱动，前端「虚拟商店」页可动态编辑商品/价格/目录/解锁条件）。
> **ServerPlugins 目录请勿再放置本目录编译出的 `shopui.dll`**，否则与主插件双实例冲突（两套钩子同时挂）。
> 前端配置入口：控制台 → 虚拟商店（`/console/shopui`，需要 manager 权限）。

**手持锡斧挥动** → 在脚底召唤一个**仅自己可见**的虚拟旅商；再次挥动拉回身边；关闭对话或下线自动消失。
旅商商店为 **40 槽（10×4）**：上方商品区 + 底部 4 个**雕像控件**，点击雕像切换商店。

## 交互

| 操作 | 效果 |
|------|------|
| 手持**锡斧**按下使用键（挥动） | 召唤虚拟旅商（仅自己可见，站定在脚底） |
| 旅商存在时**再次挥动锡斧** | 把旅商拉回身边 |
| 点击旅商对话 → 点"商店" | 打开旅商商店（40 槽：36 商品槽 + 4 雕像槽，默认宝藏袋） |
| 点击商店里的**雕像** | 雕像被"消费"（不进背包）→ 立即切换对应商店 |
| 点击旅商对话 → 关闭对话 | 旅商自动消失 |
| 直接下线 | 自动清理 |

- 商店内容**固定价格**：召唤旅商、玩家点开旅商对话、点击雕像切商店时各应用一次
- **默认初始商店 = 宝藏袋商店**（非 72 快照的未刷新初始，同样走打开后的持续 104 刷新填充）
- **72 号包全空快照（40 槽全 0）** → 玩家打开商店瞬间**完全空白**；**104 只在 `Main.npcShop>0`（商店已打开）时应用**，且 72 无法定价/置空 → 点开旅商对话后**持续高频刷新**（每 0.2s 重发 104）逐槽填充商品+雕像，**退出旅商（关对话）或点击雕像切商店才停止**
- 雕像价格恒为 0；点击雕像购买 → 服务器拦截并**回滚清空**（雕像不进入背包）→ 切换商店 → 立即刷新并停止持续刷新

## 实现原理（1.4.5 / TShock 6.1.0 源码实证）

### 仅自己可见（核心）
- 服务器创建**真实**旅商 NPC（368），出站包经 **`OTAPI.Hooks.NetMessage.SendBytes` 钩子**（Omni Ghost 同款）定向过滤：
  - `23 号包 SyncNPC`：body 前 2 字节 = NPC 索引，匹配虚拟旅商且接收者≠所属玩家 → `args.Result = Cancel`
  - `40 号包 SyncTalkNPC`：body 中 talkNPC 匹配虚拟旅商且接收者≠所属玩家 → Cancel
- 其他玩家客户端收不到该 NPC 的任何包 → 实体不存在 → 完全不可见、无法交互

### 挥动检测
- `GetDataHandlers.PlayerUpdate` + `Control.IsUsingItem` false→true 上升沿 + 手持槽位物品 `== 3500`

### 商店刷新
- **104 号包 ShopOverride**（TrProtocol 实证）：`[2长度][104][byte 槽位][short 物品][short 数量][byte 前缀][int 价格][byte buyOnce]`，socket 直发；客户端 `Main.npcShop>0` 时才应用，未开商店自动忽略
- **72 号包只能写物品 ID（无法定价/置空栏位）** → 发**全空快照**（40 槽全 0），打开瞬间商店空白；商品+雕像全靠打开后的 104 逐槽填充（104 按槽位精确覆盖，不依赖 `SetupShop` 顺序填充）
- 停止信号：1.4.5 **没有专用购买包**（19=门）→ 用**打开对话（40 包 talkNPC=旅商）**触发**持续高频刷新**（`GameUpdate` 每 0.2s 重发 104），**退出旅商（关对话 40 talkNPC=-1）/移除/下线 或点击雕像切商店**才停止

### 雕像切换商店（购买触发）
- 雕像在商店中价格 0 → 点击购买 → 客户端把雕像放入背包槽 → 发背包槽更新包（`PlayerSlot`）
- `GetDataHandlers.PlayerSlot` 钩子检测到雕像类型 → `args.Handled=true` 拦截 → `SendData(PacketTypes.PlayerSlot, ...)` 回滚客户端槽（雕像消失，原物品保留）→ 切换 `_currentShop` → 立即 104 应用新商店

## 已知限制

- 对话面板需玩家点击旅商后打开（服务端无法强制弹出）
- 服务器端存在真实 NPC 实体（对其他系统如 NPC 计数有轻微影响）
- 旅商站定不动（`aiStyle=-1`）
